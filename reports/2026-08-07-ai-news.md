## 重點新聞

### 1. Claude Code 可把自家機器接給雲端 Agent，跨裝置協作與憑證遮罩也同步強化

**發生什麼事**

Anthropic 在 8 月 7 日發布 Claude Code 2.1.224。Team 與 Enterprise 可使用 `claude self-hosted-runner`，把自己的機器或容器提供給 Claude Code 網頁、手機與桌面工作階段執行。macOS 與 Linux 的工作階段也能透過 `ListAgents` 找到其他機器上的 session，再以 `SendMessage` 跨工作階段互傳訊息。

同一版加入 `archive` plugin source，可從 HTTPS zip 安裝外掛並選擇用 SHA-256 固定內容；sandbox 則新增 JWT claim 遮罩、AWS credential pair 與 SigV4 重新簽章等選項。安全修正也包含尾斜線 `denyRead` 規則曾可被繞過、超長專案路徑可能錯連其他專案 session，以及訊息寫入失敗卻誤報成功等問題。

**具體進步**

需要私有網路、特殊 Node／瀏覽器環境、內部套件庫或既有運算硬體的遠端任務，現在可留在團隊控制的 runner 上，不必先把整套環境搬到供應商主機。跨 session 訊息的待核准、失敗回報與 sandbox 違規細節也更清楚，長任務較不容易因隱藏的傳送或隔離錯誤卡住。

憑證遮罩能針對 JWT 與 AWS 請求的結構處理敏感內容，比只靠一般字串比對更適合需要代理連內部服務的工作流。不過自架 runner 仍是可執行程式碼的高權限節點，不能因為由 Claude Code 管理就省略主機隔離與稽核。

**對工作的影響**

- 前端團隊可把需要內網 npm registry、真實瀏覽器、特定 Node 版本或大型 monorepo cache 的建置與測試交給自架 runner，再從桌面或手機追蹤。
- 導入時應為 runner 使用獨立帳號，限制 `--base-dir`、檔案權限與網路出口，並實測長路徑、`denyRead`／`denyWrite`、JWT 與 AWS 憑證遮罩。
- UI/UX 團隊可參考這次跨裝置任務設計：清楚區分待核准訊息、自動送達、傳送失敗、斷線與重連，不要只用短暫 toast 表示關鍵狀態。

**日期證據：** 官方 changelog 的 2.1.224 節明確標示「August 7, 2026」。

**產品狀態：** 已正式發布；self-hosted environments 限 Team 與 Enterprise，跨機器 `SendMessage` 標示適用 macOS 與 Linux。

### 2. ChatGPT Voice 支援檔案與 Projects，可直接用語音追問文件和專案脈絡

**發生什麼事**

OpenAI 在 8 月 7 日更新 ChatGPT Voice。GPT-Live 語音對話現在可上傳檔案、分析內容並持續追問，也能直接在 Projects 中使用語音，引用近期專案聊天、來源與專案指令。使用者不必先把文件摘要轉貼成文字，便能邊查看 PRD、研究資料或設計規範，邊用口頭方式討論。

官方 Voice 說明顯示，Live 可在同一聊天中搭配文字與圖片，現在再加入檔案與 Projects；但它仍不會自行從 ChatGPT Library 搜尋或附加檔案。不同方案、地區、workspace 設定與應用程式版本也可能影響可用的 Voice 選項。

**具體進步**

語音、文件與專案脈絡現在能留在同一條對話裡，少了先建立新聊天、重新貼背景、再把口頭討論搬回專案的手工切換。這尤其適合需要反覆追問的長文件走查，而不只是一次性的語音提問。

Voice transcript 不是逐字紀錄，重疊說話、背景噪音與快速對話仍可能造成差異。重要結論應要求指出來源頁碼、段落或畫面，再回到原檔核對；不能把語音回覆直接當成已確認的規格變更。

**對工作的影響**

- 前端與 UI/UX 團隊可在走查 PRD、訪談逐字稿、可及性報告或設計規範時，用語音要求整理風險、追問衝突與產生待辦。
- 平面與網頁設計可把品牌來源與既有討論留在 Project，口頭要求比較版型方向、整理回饋或產生交付清單，不必每次重述背景。
- 含客戶資料或未公開素材時，要先確認 workspace 權限、資料控制與檔案分享範圍；關鍵決策仍應轉成可搜尋、可審閱的文字紀錄。

**日期證據：** ChatGPT Release Notes 以「August 7, 2026」列出 Files and Projects in ChatGPT Voice。

**產品狀態：** 已正式發布；實際可見性仍受方案、地區、workspace 設定與應用程式版本影響。

## 對工作流的意義

今天兩則更新都在縮短「背景資料」與「實際執行」之間的距離：Claude Code 能在團隊自己的環境跑長任務，ChatGPT Voice 能直接沿用文件與 Project 脈絡。對前端與設計團隊而言，效率提升的前提仍是把執行環境、資料權限、核准狀態與可追溯的文字紀錄一起設計好。
