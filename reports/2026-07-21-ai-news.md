## 重點新聞

### 1. Gemini 3.6 Flash 與 3.5 Flash-Lite 正式上線，agent 更省 token 也更快

Google 已把 Gemini 3.6 Flash 與 3.5 Flash-Lite 推向正式環境。前者主打程式開發、多步工具呼叫與複雜視覺理解；後者主打低延遲、高吞吐的批次任務。兩者都可透過 Gemini API 與 AI Studio 使用，3.6 Flash 也已開始推向 Antigravity、Gemini 應用與 GitHub Copilot。

- 具體進步：Gemini 3.6 Flash 相比 3.5 Flash 在 Artificial Analysis 的整體測試中平均少用 17% 輸出 token，並減少工具呼叫與推理步驟；官方定價為每百萬 input/output token 1.50/7.50 美元。3.5 Flash-Lite 輸出速度可達每秒 350 token，定價 0.30/2.50 美元，讓團隊可依任務難度分層選模型，不必每個 agent 都使用同一個高成本配置。
- 工作影響：前端與 UI/UX 團隊可用 3.6 Flash 處理跨檔重構、從截圖或藍圖還原介面、調整設計系統與執行需多次工具呼叫的 coding agent；再交給 3.5 Flash-Lite 批次生成網頁概念、摘要文件、轉換 JSON 或當平行子 agent。
- 遷移注意：新版模型已將 `temperature`、`top_p` 與 `top_k` 等 sampling 參數標示為 deprecated，並不允許 prefilled model turn。舊整合應移除這些設定，將指令改放 `system_instruction` 或 structured outputs，再重測 token 預算與工具呼叫結果。

## 對工作流的意義

這次更新不是只把同一個模型做快，而是讓團隊更容易用「複雜任務交給 3.6 Flash、高量輕量任務交給 3.5 Flash-Lite」的層級化方式設計 agent。對前端、網頁與平面設計工作，最直接的測試方式是挑一個真實專案，分別比較跨檔編輯、視覺還原、多方案發散與批次轉檔的成功率、token 用量和實際等待時間。Gemini 3.5 Flash Cyber 當天僅預告即將對政府與可信任伴開放限量試點，因此不當作已公開可用新聞列入。
