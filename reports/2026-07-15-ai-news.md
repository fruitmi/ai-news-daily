# 2026-07-15 AI 每日新聞

## 今日摘要

2026-07-15 整理 3 則值得追蹤的 AI 更新：ChatGPT 讓團隊能保存更完整的長篇偏好與工作規則，Adobe 與 Microsoft 則把 agent 工具與多模型選擇帶進企業工作管理和受管制環境。Google Chat 的外部群組對話不是 AI 功能，因此沒有收錄；Google Sheets 的 Gemini 額度變化源自 7 月 7 日公告，也沒有改標成 7 月 15 日新消息。

## 重點新聞

### 1. ChatGPT 自訂指令上限提高到 5,000 字元

OpenAI 把 ChatGPT 自訂指令的長篇欄位上限從 1,500 提高到 5,000 字元，Plus、Pro、Business、Enterprise 與 Education 使用者現在可保存更完整的回覆風格與行為規則。這項更新作用在 ChatGPT 的 Personalization 設定，不是 API 的 system message 變更；Free 方案也不在這次擴容名單中。

- 具體進步：可保存的常駐規則增加到原本的三倍以上，較能一次放入語言、格式、設計系統、程式規範與交付要求，減少每次開新對話重貼背景或因規則被截短而漏掉限制。
- 工作影響：前端與設計團隊可把繁體中文、元件命名、無障礙檢查、品牌語氣、版型限制與輸出格式整理成固定指令；仍應避免放入客戶機密、金鑰或未公開資料，並把專案專屬規格留在 Project 或版本控管文件。
- 當日官方來源：[OpenAI ChatGPT Release Notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)
- 操作參考：[OpenAI Help：ChatGPT Custom Instructions](https://help.openai.com/en/articles/8096356-chat-preferences-for-chatgpt)

### 2. Adobe Workfront MCP 新增品牌檢查、批次核准與留言工具

Adobe Workfront 的 26.7 fast release 在 7 月 15 日把一批新 MCP 工具帶進正式環境，可讓 ChatGPT、Claude 等相容平台查找 Workfront 資料、批次提醒核准、管理核准參與者、處理留言，並檢查素材是否符合品牌規範。全體季度版預定 7 月 16 日上線；原有的 Search objects 與 Resolve field name 工具已淘汰，既有流程需要改用新工具。

- 具體進步：agent 不再只做單筆搜尋或更新，現在能處理批次核准、完整留言流程和品牌規範驗證，減少專案經理與設計團隊在 Workfront 畫面中逐項查找、催件與手動檢查素材的步驟。
- 工作影響：平面與 UI/UX 團隊可請 agent 彙整待核准素材、批次提醒利害關係人、查出相關留言，再先跑品牌規範檢查；正式採用前要確認 Workfront 權限、唯讀／寫入工具設定與人工核准節點，目前 MCP 仍限 AWS 上的 Workfront 客戶。
- 當日上線資訊：[Adobe Workfront 26.7 AI enhancements](https://experienceleague.adobe.com/en/docs/workfront/using/product-announcements/product-releases/release-26-q3/26-q3-ai)
- 操作參考：[Configure the Adobe Workfront MCP server](https://experienceleague.adobe.com/en/docs/workfront/using/basics/workfront-mcp-server/configure-workfront-mcp-server)
- 使用案例：[Use the Adobe Workfront MCP server](https://experienceleague.adobe.com/en/docs/workfront/using/basics/workfront-mcp-server/use-workfront-mcp-server)

### 3. Microsoft 365 GCC 開始讓非聯邦客戶選用 Anthropic 模型

Microsoft 從 7 月 15 日起分批在 Microsoft 365 管理中心加入新設定，讓 Government Community Cloud 的非聯邦客戶可選擇在 Microsoft 365 Copilot、Copilot Studio、Power Platform 與其他支援流程使用 Anthropic 模型。功能預設關閉，且不適用聯邦 GCC、GCC High、DoD 與其他 sovereign cloud。

- 具體進步：原本無法在這類受管制租戶中選用的外部模型，現在可由管理員按使用者或群組開放，讓團隊比較不同模型在內容生成、研究與 agent 編排上的品質，而不必另外建立一套獨立入口。
- 工作影響：承接美國公部門專案的前端與設計團隊，可在受控帳號內比較 Claude 與既有 Copilot 模型處理規格、簡報或內容草稿的表現；啟用前必須確認資料會在 FedRAMP 授權政府雲之外處理，並由法務、資安與管理員共同決定適用資料範圍。
- 當日上線資訊：[Microsoft Learn：Anthropic models in Microsoft Online Services](https://learn.microsoft.com/en-us/microsoft-365/copilot/connect-to-ai-subprocessor)
- 操作參考：[Copilot Studio：Choose an external model](https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-select-external-response-model)

## 對工作流的意義

今天三則更新的共同點，是把「提示規則、工具權限與模型選擇」變成可以長期管理的工作設定。個人與小團隊可先用較長的 ChatGPT 自訂指令固定品質底線；使用 Workfront 的設計組織可把催核准、查留言和品牌初檢接到 agent；受管制環境則應先把模型選擇當成資料治理決策，而不是只比較生成品質。
