# 首頁文章定位與文章頁圖片設計

日期：2026-07-17

## 目標

改善從 Banner 進入文章清單、切換文章分頁，以及在文章詳情閱讀 TOP3 圖片的體驗，同時維持現有 Style D、資料結構與 GitHub Pages 靜態部署方式。

## 已選方案

採用現有 HTML、CSS 與 JavaScript 內做最小調整，不新增框架或資料欄位。

- 首頁共用一個 `scrollToFirstArticle()` 行為，供 Banner 按鈕與分頁切換呼叫。
- 文章頁依既有 TOP3 檔名規則推導圖片路徑，舊版不規則檔名使用精確映射作為 fallback。
- 不建立新的圖片 JSON，也不要求每日自動化重複維護 `article.html` 的圖片 map。

未採用的方案：每次手動同步兩頁的 `featuredImages` map，容易在每日更新時漏掉；另建共享圖片 JSON，會增加目前不必要的資料與載入流程。

## 首頁滑動行為

### Banner 底部按鈕

- 在 Hero 最底部中央加入可鍵盤操作的按鈕。
- 圖示使用簡潔向下箭頭，不使用 emoji 或額外圖片資產。
- 按鈕採低幅度上下移動與輕微 cyan 邊框提示，符合既有 cockpit 視覺。
- 使用者偏好減少動畫時，停用循環位移。
- 點擊後平滑滑到目前清單的第一個 `.intel-row`，並保留固定 topbar 所需間距。
- 若篩選結果沒有文章，按鈕不執行滑動。

### 分頁切換

- 上一頁或下一頁完成 `renderStories()` 後，定位到新頁面的第一個 `.intel-row`。
- 滑動目標是文章卡片本身，不是 `ALL ARTICLES` 標題。
- 使用平滑滑動；偏好減少動畫時改為立即定位。
- 篩選、搜尋、標記已讀及收藏重新渲染時，不強制滑動，避免輸入過程中畫面跳動。

## 文章頁圖片

- 圖片放在摘要後、`具體進步` 前。
- 僅 rank 1 至 3 的文章嘗試使用 TOP3 圖片。
- 新版圖片路徑依 `assets/featured-YYYY-MM-DD-0RANK.png` 推導。
- 2026-07-09 舊圖片保留既有精確映射。
- 圖片容器寬度為 `min(100%, 1000px)`，以 `margin-inline: auto` 置中。
- 保持寬扁新聞視覺並使用 `object-fit: cover`；手機版隨容器縮小。
- 圖片載入失敗時隱藏整個 figure，不能顯示破圖或空框。

## 可及性與錯誤處理

- Banner 按鈕提供清楚的 `aria-label` 與可見 focus 狀態。
- 所有圖片保留文章標題作為替代文字。
- 遵守 `prefers-reduced-motion`。
- 沒有文章或沒有圖片時維持原版面，不顯示無效控制或空容器。

## 驗證

- 驗證 `index.html` 與 `article.html` 的內嵌 JavaScript 語法。
- 桌面與手機尺寸確認 Banner 按鈕不遮擋篩選面板或內容。
- 測試上一頁、下一頁皆停在新頁第一篇文章。
- 測試 Banner 按鈕停在目前第一篇文章。
- 測試有 TOP3 圖片、沒有圖片及圖片載入失敗三種文章頁狀態。
- 完成後提交並推送 `main`，再確認 GitHub Pages 線上建置成功。
